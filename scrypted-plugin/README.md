# Golmar 4+n Intercom Plugin for Scrypted

This is a Golmar 4+n Intercom plugin for Scrypted

The plugin will connect to your Golmar 4+n Intercom and allow two way audiousing Scrypted.

I used a Raspberry Pi Zero with Behringer U-CONTROL UCA222 USB audio card

Install using:
```
cd ./scrypted-golmar-intercom                             
npm run build
npm run scrypted-deploy 127.0.0.1
```
